# HackerRank Practice

A daily log of coding problems I'm solving on [HackerRank](https://www.hackerrank.com/profile/shoaibmahar347) as I practice — mostly Java, with a growing mix of algorithms, data structures, and language-feature exercises.

Each solved problem lives in its own folder, named after the problem (and sometimes the approach used, e.g. *"Between Two Sets using lcm and gcd method"*), so it's easy to find and revisit later.

## Why this repo exists

I'm using this as a running practice log — solving a problem (or a few) most days, uploading the solution as I go, and occasionally revisiting a problem with a different or more optimal approach. It's less a "finished project" and more a public scratchpad of consistent practice.

## What's inside

Problems are grouped loosely by theme (folder names make this self-explanatory):

- **Warm-up / basic programming** — e.g. Compare the Triplets, Mini-Max Sum, Birthday Cake Candles, Diagonal Difference
- **Arrays & strings** — e.g. 2D Array DS, Left Rotation, Circular Array Rotation, Compress the String, Company Logo
- **Sorting & greedy** — e.g. Day-2-Sorting, Climbing the Leaderboard, Grading Students, Drawing Book
- **Data structures** — e.g. linked list operations (insert at tail/position, delete duplicate-value nodes), Equal Stacks, Game of Two Stacks
- **Math & number theory** — e.g. Between Two Sets, Numerical Palindrome, Find Digits, Angry Professor
- **Java language features** — e.g. Generics, HashSet, Iterators, Exception Handling, Regex, Varargs, Abstract Classes, Interfaces, Method Overriding/Overriding with `super`, BigInteger/BigDecimal
- **Design patterns** — e.g. Factory Pattern
- **Misc / logic puzzles** — e.g. Cut the Sticks, Jumping on Clouds, Beautiful Days, Count Valleys

Some problems have multiple solution folders when I revisited them with a different technique (e.g. brute force vs. optimized), so you may see the same problem name appear more than once with a suffix describing the method.

## Structure

```
HackerRank/
├── <Problem Name>/          # one folder per problem
│   └── Solution.java        # (or .py, depending on the problem)
├── <Problem Name using X method>/
│   └── Solution.java
└── ...
```

Folder names double as a lightweight index — no separate problem-list file is maintained since GitHub's file browser already sorts them alphabetically.

## Languages

Primarily **Java**, since most of this practice ties into strengthening core Java fundamentals (collections, OOP, generics, exception handling) alongside general problem-solving. Occasional problems may use other languages as I branch out.

## Progress

This repo is updated regularly (aiming for daily) as I work through more problems. Commit history is the best place to see recent activity.

## Usage

Feel free to browse any folder for a reference solution. These are practice solutions, not necessarily the most optimized possible — some folders intentionally keep a "brute force" version alongside a cleaner one for comparison.
